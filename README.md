# Zeravorn

## Setup

Zeravorn is a server-authoritative Minecraft Java Fabric MOBA project.

The implementation roadmap and project rules are documented in `docs/`, beginning with
`Zeravorn_CODEX_Implementation_Playbook_v1.0.md`.

For environment setup, see the [Fabric Documentation](https://docs.fabricmc.net/develop/getting-started/creating-a-project#setting-up).
