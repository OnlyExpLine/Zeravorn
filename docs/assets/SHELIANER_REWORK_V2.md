## Модель и backup

В Blockbench: File → Open Model → `assets/source/blockbench/heroes/shelianer/shelianer.bbmodel`. Формат Generic Model / free, полигональные меши, встроенная текстура. Контрольная боевая стойка: Animate → `shelianer.review_combat_pose`. Это статическая поза, не отполированная способность.

Предыдущая модель сохранена рядом как `shelianer_v1_backup.bbmodel`. Старые first-person и оружие находятся в `archive_v1/`; прежние исходники генератора — `tools/blockbench/shelianer/archive_v1/`. Backup не перезаписывается.

Рост до вершины капюшона — 29,88 единицы, 1,8675 блока. Вперёд −Z; 16 единиц = блок. Gameplay hitbox 0,60 × 1,80 из Balance не изменён. Декоративная броня и оружие выступают за хитбокс; gameplay-код и конфигурации не менялись.

Перенос ножа в руку, скрытие оружия при броске и runtime projectile attachment относятся к следующему этапу.

## Validation и clipping

`validation.json`: структура, UV, конечные численные значения, ссылки мешей/костей, границы времени, loop seams, старый bone API и sockets — **PASS**. Подтверждены шесть поясных ножей. 112 поз оценены на корректность трансформаций. 2210 ключей предплечий прошли контроль направления/диапазона. Ошибка высоты опорной стопы по кинематической проверке ≤0,00106 authoring unit; это не тест всех вершин подошвы.

Выборочный triangle-intersection audit: 33 позы idle/walk/run/basic/Q/E/F/R + combat, 1782 пары «основной наруч / ладонь / тело клинка — торс / грудная пластина / капюшон / лицо». **Пересечений в этой выборке не найдено.** Проверка не включает все кадры, кромки/гарды, соседние слои брони или ткань против ног. Намеренные перекрытия слоёв существуют. Отсутствие любого clipping во всей анимации не гарантируется.

Прежние клипы сохранены для проверки рига; финальная полировка не выполнялась. При большом подъёме руки плечевой пакет жёстко следует за плечом: позднее может потребоваться коррекция на новой shoulder bone. Широкие панели плаща в крайних позах требуют отдельной animation/clipping-проработки.

Blockbench GUI import не запускался. In-game интеграция и performance profiling не выполнены. Бюджет 303 элемента / 8808 треугольников; FPS этим не доказан. glTF находятся в `exports/`. Материалы и микроорнамент проще художественной фактуры concept sheet.

## Воспроизведение и следующий этап

`node tools/blockbench/shelianer/generate_shelianer.mjs`

Геометрия: `tools/blockbench/shelianer/geometry_v2.mjs`. Перед записью основных моделей генератор проверяет кандидаты и совместимость костей; backup остаётся неизменным. Генератор заменяет текущие собственные ассеты Shelianer, поэтому ручной вариант сохранять отдельно.

К финальной animation phase **не переходить до визуального подтверждения владельца**. После подтверждения — перенос Q-ножа, бросок E, широкие панели плаща, плечи, R и полный clipping audit. Сейчас остановка на геометрии, previews и отчёте согласно заданию.
